## 💻 Local Development & Server

To run the full site locally on port `3000`:

```bash
# Clone repository
git clone https://github.com/saurabhhhcodes/autonomiq-website.git
cd autonomiq-website

# Launch static server on port 3000
python3 -m http.server 3000

# Open in browser
http://localhost:3000/
```
