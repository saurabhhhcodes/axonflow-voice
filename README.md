## 🌐 Deployment

The site is deployed on **Vercel** at [axonflow.in](https://axonflow.in). The root `vercel.json` rewrites all routes to `/frontend/` directory.

### **SEO Optimizations**
- All pages have JSON-LD structured data (Organization, Service, Course, FAQ, Review, BlogPosting schemas)
- Open Graph & Twitter Card meta tags for social sharing
- Canonical URLs + hreflang tags for India geo-targeting (`en-IN`)
- `robots.txt` + `sitemap.xml` for search engine crawling
- Semantic HTML + ARIA labels for accessibility
- Core Web Vitals optimized (deferred JS, lazy images, preloaded fonts)
